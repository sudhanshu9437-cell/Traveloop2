## 📌 Project Description
This project is a static website developed using HTML, CSS & Basic Javascript.  
The purpose of this project is to practice front-end web development concepts such as layout design, styling, responsiveness, and user interface creation.

---

## ✨ Implemented Features
- Responsive website layout  
- Navigation bar  
- Cards/sections for content display  
- Images and text alignment  
- Hover effects using CSS  
- Clean and simple UI design
